# Navalha de Ouro

Projeto front-end desenvolvido como parte do processo de aprendizado e consolidação dos estudos sobre Tailwind CSS.

## Sobre o projeto

O Navalha de Ouro é uma landing page voltada para apresentação de uma marca/negócio, com foco em visual moderno, responsivo e clean. A ideia principal foi aplicar de forma prática os conceitos aprendidos sobre utilitários, classes responsivas, espaçamento, tipografia, cores e layout em um projeto real.

## Tecnologias utilizadas

- HTML5
- Tailwind CSS
- JavaScript (quando necessário)
- Design responsivo

## Objetivo

Este projeto foi criado com o propósito de reforçar e concretizar o aprendizado em Tailwind, transformando teoria em uma aplicação visual funcional. A prática foi essencial para entender melhor o fluxo de desenvolvimento, além de explorar como o framework ajuda a criar interfaces de forma mais rápida e organizada.

## Resultado

O resultado final busca transmitir uma identidade visual forte, com estrutura bem organizada, layout moderno e boa experiência em diferentes tamanhos de tela. Foi uma oportunidade de consolidar conhecimentos e desenvolver um projeto prático que simula uma situação real de criação de interface front-end.

## Observação

Este é um projeto de estudo e aprimoramento pessoal, com foco em aplicar os conhecimentos de Tailwind em um cenário real de desenvolvimento web.
